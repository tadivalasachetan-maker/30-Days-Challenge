1. Start.

2. Declare arrays for water usage, daily targets and zone names.

3. Display the menu: Input, Report and Exit.

4. Enter the user's choice.

5. If the choice is 1, enter the daily target and water usage for 5 zones and 7 days. Re-enter invalid values.

6. If the choice is 2, calculate the total, average, exceeded days and unusual usage days for each zone using loops and pointers.

7. Display the water consumption report.

8. Identify the zone with the highest water consumption and recommend it for conservation.

9. If the choice is 3, exit the program.

10. If the choice is invalid, display an error message.

11. Repeat the menu until Exit is selected.

12. Stop.
